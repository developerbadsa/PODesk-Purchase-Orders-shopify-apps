# 30-60-90 Day Plan

## Main Principle

Sales discovery and product build must run together.

If only code happens, the business risk stays unknown.

If only outreach happens, there is nothing to convert into product.

## First 14 Days: Validate

Goal:

- prove real merchant pain
- collect workflow samples
- get first paid audit or pilot

Daily work split:

- 50% outreach and calls
- 30% landing page and offer assets
- 20% product architecture and prototype

Tasks:

1. Create one-page landing page.
2. Create Stocky migration checklist.
3. Build 200-lead list.
4. Send 50 targeted messages/day.
5. Book 5-10 calls.
6. Ask for real workflow samples.
7. Try to sell $299 migration audit.

Decision gate:

- Continue if 3+ serious calls or 1 paid audit.
- Reposition if no meaningful replies after 200 targeted messages.

## Days 15-30: Build Narrow MVP

Goal:

Create working internal beta for first pilot merchants.

Build:

- Shopify OAuth
- product/variant/location/inventory sync
- order history sync for sales velocity
- supplier CRUD
- purchase order CRUD
- Stocky CSV/manual import
- reorder table
- CSV export

Do not build:

- billing
- marketplace sync
- full AI
- full dashboard polish
- automatic inventory write-back

Sales:

- continue 25-50 messages/day
- book 2-3 calls/week
- push paid audit or pilot

## Days 31-60: Pilot

Goal:

Have 3-5 merchants using a narrow workflow.

Product:

- fix sync reliability
- improve import mapping
- add low stock digest
- add PO PDF if requested
- add receiving only if repeated demand
- add onboarding checklist

Sales:

- convert audit users to monthly plan
- ask for testimonials
- write first case study
- build agency referral list

Pricing:

- early plan: $99/month
- setup: $299-$499

## Days 61-90: Public Beta

Goal:

Reach first consistent MRR and prepare Shopify App Store path.

Product:

- sync status
- webhook processing
- error logs
- basic app billing if ready
- better dashboard
- documentation
- privacy policy
- support email

Sales:

- publish comparison pages
- launch "Stocky migration checklist"
- contact agencies
- ask pilot users for referrals

Target:

- 5-10 paying customers
- $500-$2,000 MRR
- 1-3 testimonials

## 6-Month Target

Only realistic if validation works:

- 25-50 paying customers
- $3k-$10k MRR
- stable MVP
- clear ICP
- 5+ testimonials/reviews

## 12-Month Target

If churn is low:

- 100-200 paying customers
- $10k-$30k MRR
- Shopify App Store ranking
- agency channel
- stronger PO, supplier, receiving, reorder workflows
