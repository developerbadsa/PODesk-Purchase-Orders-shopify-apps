## Overview

This document defines the exact screenshots required for the Shopify App Store listing, user documentation, and promotional materials.

Every screenshot must showcase realistic merchant data and explicitly demonstrate how PODesk solves operational purchasing challenges.

## Technical Formatting Rules

1. **Window Size**: 1280x800 or 1440x900 pixels (16:10 standard desktop aspect ratio).
2. **Browser Theme**: Clean light mode inside Shopify Admin. Hide personal browser bookmarks and extensions.
3. **Image Format**: PNG or WebP with crisp 2x resolution.
4. **Framing**: Capture the embedded app frame within Shopify Admin to prove native integration.
