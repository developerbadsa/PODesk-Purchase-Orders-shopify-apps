What Is Done

  • Installed Shopify embedded app opens in development store.
  • Inventory sync works without query-cost failure.
  • Merchant can create suppliers and map SKUs.
  • Merchant can create, send, print, and track purchase orders.
  • Merchant can import supplier mappings from CSV with row-level validation.

What Is Still Missing

  • Receiving workflow for partial/full PO receiving.
  • Shopify billing and paid trial flow.
  • Production deployment database and monitoring.
  • Privacy policy, terms, screenshots, demo video, App Store listing.
  • Automated supplier email delivery and PDF download.
  • Historical Stocky PO archive import.

Next Priority

Build receiving workflow first. It closes the purchase order loop and makes PO statuses operational instead of just labels.

Recommended order: Receiving workflow, billing, production hardening, App Store assets.
